# Coding Club Quiz 🎯

A super simple quiz app (HTML/CSS/JS) designed for high school coding clubs.

## Run it
Just open `index.html` in a browser.

## How to contribute
See [CONTRIBUTING.md](CONTRIBUTING.md).

## Ideas for club members
- Add more questions to `questions.json`
- Add categories (math, science, history)
- Add a timer
- Add a “review answers” screen
