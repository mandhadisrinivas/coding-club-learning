# Contributing

Welcome! This repo is designed for beginners.

## First contribution checklist
1. Fork the repo
2. Create a branch: `feature/your-feature-name`
3. Make your change
4. Test by opening `index.html`
5. Open a Pull Request

## Good first issues
- Add 5 new questions
- Improve button styling
- Add a start screen
- Add “shuffle choices”

## Style tips
- Keep code simple and readable
- Use clear variable names
- Add comments if something is confusing
